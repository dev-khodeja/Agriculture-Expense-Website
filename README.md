# 🌿 Smart Agriculture Management System

A modern and responsive Agriculture Management System built with React.js for farmers and agricultural management.

This platform helps farmers manage land, crops, soil analysis, disease information, farming expenses, and crop planning in a simple Bengali interface.

---

## 🚀 Features

### 🗺️ Land Management
- Store multiple land information
- Soil type management
- Crop history tracking

### 🌾 Crop Management
- Crop planning and monitoring
- Planting to harvesting tracking
- Crop status management

### 📅 Smart Calendar
- Fertilizer reminders
- Irrigation schedule
- Harvest notifications

### 🦠 Disease Information System
- Common crop disease database
- Symptoms and prevention details
- Treatment suggestions

### 💰 Expense Tracking
- Seed cost management
- Fertilizer and labor expenses
- Profit and loss estimation

### 📊 Yield Analysis
- Seasonal crop comparison
- Production analysis
- Farming improvement suggestions

## 🌱 Soil Analysis Support

The system currently supports:

- এঁটেল মাটি (Clay Soil)
- বেলে মাটি (Sandy Soil)
- দোআঁশ মাটি (Loamy Soil)

Each soil type includes:
- pH level
- Suitable crops
- Soil description

---

## 🦠 Disease Database

Includes information about:

- Tomato Blight Disease
- Wheat Rust Disease

Features:
- Symptoms
